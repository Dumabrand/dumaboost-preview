Go-live checklist

Everything needed before DumaBoost takes real money. Automatic checks update themselves; tick the paperwork items when done.

2/29

7% done

Website

  • Real domain with HTTPS

    APP_URL is http://localhost:8000. Set it to https://dumaboost.com once the domain points to Hostinger.

  • Live mode (debug off)

    Set APP_ENV=production and APP_DEBUG=false in .env.

  • Preview password removed

  • Background jobs running (cron)

    Add the every-minute cron job: php …/artisan schedule:run

  • Production database (MySQL)

    Use the Hostinger MySQL database in .env.

Payments

  • ClickPesa selected

    Set PAYMENT_DRIVER=clickpesa after your merchant account is approved.

  • ClickPesa keys entered

    Add CLICKPESA_CLIENT_ID and CLICKPESA_API_KEY from the ClickPesa dashboard.

  • Webhook checksum on

    Enable checksum in ClickPesa and set CLICKPESA_CHECKSUM_KEY.

  • A real payment went through

    Place a TSh 1,000 test order with your own phone.

  • Payment fee set from your contract

    Update PRICING_GATEWAY_FEE_BP with the rate ClickPesa gives you (350 = 3.5% is our estimate).

Supplier & prices

  • SMM panel connected

    Admin → Suppliers → Add a supplier (API URL + key).

  • Panel has balance

    Top up your panel balance, then Sync.

  • Prices synced this week

    Admin → Suppliers → Sync prices & balance.

  • Exchange rate set

    Set SMM_FX_TZS_PER_USD in .env.

  • Packages linked to the panel

    0 visible packages are routed to a panel. Link them in Suppliers → Browse catalog.

  • No placeholder prices left

    22 visible packages still use placeholder costs — link them to panel items.

Security & support

  • Secret admin address

    Set ADMIN_PATH to something only you know.

  • All staff use 2-step

  • Codes by SMS or WhatsApp

    Set SMS_DRIVER=beem with your Beem keys and approved sender ID (and/or WHATSAPP_DRIVER=cloud). Until then, phone sign-up codes cannot be delivered; email still works.

  • Emails are sent

    Set MAIL_MAILER=smtp with your Hostinger mailbox (smtp.hostinger.com, port 465).

  • Alert email set

    Set DUMABOOST_ALERT_EMAIL to get problem alerts.

  • WhatsApp support number

    Set DUMABOOST_SUPPORT_WHATSAPP (digits only, e.g. 2557XXXXXXXX).
